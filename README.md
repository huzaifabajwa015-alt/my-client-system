# 👥 Client Management System

A simple and clean Client Management System built with **Python** and **Streamlit**.

## Features

- Add new clients
- Search clients by name
- Update client status (Active / Pending / Completed)
- Delete clients
- Data automatically saved in JSON file
- Download data as JSON
- Clean and professional UI with sidebar and metrics
